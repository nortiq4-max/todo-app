# Vibe coding の進め方（AIと一緒に作る手順）

AIにコードを書いてもらうと速く進みます。ただし、任せきりにすると「動くけど説明できないコード」が残り、資格の勉強にもなりません。
ここでは、AIを使いながら自分の力もつく進め方をまとめます。

## 基本の流れ（1つの機能ごとに回す）

1. **仕様を自分の言葉で書く**：CHALLENGE.md の表を読み、「何を入れたら何が返るか」を1〜2行でメモする
2. **テストを先に読む**：`tests/test_core.py` の該当するテストを読み、合格の条件を確かめる
3. **AIに小さく頼む**：関数1つずつ頼む。仕様とテストを一緒に渡す
4. **出てきたコードを読む**：分からない行があれば、そのままAIに「この行は何をしている？」と聞く
5. **テストで確かめる**：`python -m pytest -q` を実行する。失敗したらエラーをAIに見せて直す
6. **小さくコミットする**：メッセージに「何を・なぜ」を書く。Issueがあれば `Closes #1` を入れる
7. **プルリクエストに記録を残す**：使ったプロンプトと、AIの提案から自分で直した点を説明欄に書く

## 頼み方の例

```text
Pythonで次の関数を書いてください。
- 関数：add_task(tasks, title)
- tasks はタスクの辞書のリスト。タスクは {"id": 1, "title": "牛乳を買う", "done": False}
- title の前後の空白は取り除く。空になったら ValueError
- id は今ある最大の id + 1（最初は 1）
- 追加したタスクを返す
このテストに合格するようにしてください：
（tests/test_core.py の該当するテストを貼る）
```

```text
このエラーが出ました。原因と直し方を、初心者にも分かるように説明してください。
（pytest の出力を貼る）
```

```text
次のコードを1行ずつ説明してください。特に、なぜこの書き方なのかを知りたいです。
（自分のコードを貼る）
```

## やってはいけないこと

- **秘密情報を貼らない**：パスワード、APIキー、トークン、個人情報はAIに渡さない
- **理解せずにコミットしない**：説明できない行が残ったら、分かるまで聞くか書き直す
- **テストを書き換えて合格させない**：テストは仕様そのもの。コードの方を直す
- **ライセンスを無視しない**：AIが出したコードが既存のコードとそっくりなら、出どころを確かめる

## 資格の勉強とつなげる

- GH-900は「GitHubで共同作業する力」を問う試験です。AIにコードを書かせても、ブランチ、プルリクエスト、レビュー、Issue、Actions の操作は自分の手でやりましょう
- 公式の学習コンテンツと無料の練習問題（Microsoft Learn）も合わせて使うと、知識の抜けが見つかります
